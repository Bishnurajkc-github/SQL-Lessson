# Long-Term Technology Learning Roadmap

This roadmap tracks completed learning, current studies, and future
technology goals. It is a flexible learning path, not a strict timetable.

---

## Phase 1 – Python Fundamentals

**Status: Basic knowledge acquired | Revision planned**

Previously studied Python fundamentals. These concepts will be
revisited and strengthened through practical exercises and projects.

Topics:
- Variables, data types and operators
- Conditions and loops
- Functions and modules
- Lists, dictionaries, tuples and sets
- File handling
- Error handling
- Basic object-oriented programming

---

## Phase 2 – SQL and SQLite Fundamentals

**Status: Completed – 30 Lessons**

Completed a structured SQL learning sequence using SQLite.

Topics covered:
- Relational database concepts
- Tables, rows and columns
- SQL CRUD operations
- Filtering and sorting
- Aggregate functions
- GROUP BY and HAVING
- Primary keys and foreign keys
- JOIN operations
- Self joins
- Subqueries
- IN and NOT IN
- EXISTS and NOT EXISTS
- Correlated subqueries
- Views

Further database topics such as indexes and transactions
can be explored when needed.

---

## Phase 3 – Python + SQLite

**Status: Currently Learning – Lesson 1 Started**

- Database connections
- Connection and cursor objects
- Executing SQL through Python
- Fetching and processing records
- Parameterized queries
- CRUD operations using Python
- Database error handling
- Building practical database applications

## Immediate Learning Goal

Complete the practical Python + SQLite learning sequence.

Develop a strong understanding of how Python connects to databases,
executes SQL queries, retrieves records and performs database operations.

Apply this knowledge later when building Flask applications.

---

## Learning Philosophy

- Understand concepts rather than simply memorizing syntax.
- Learn through practical examples and hands-on exercises.
- Revisit earlier topics whenever deeper understanding is needed.
- Build progressively from simple exercises to real-world projects.
- Use AI as a learning and problem-solving assistant, not merely
  as a code generator.
- Focus on independent thinking, debugging and practical skills.

---

## Final Goal

Become a practical Full-Stack Developer capable of designing,
building, maintaining, improving and deploying real-world web applications.

Develop the confidence to understand the code, make informed
technical decisions and use modern development tools effectively.
